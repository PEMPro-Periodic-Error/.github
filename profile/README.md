# PEMPro

> One named PEMPro curve. Finish the sample. Leave a note the next person can read.

## How PEMPro Sits

PEMPro does not replace the mount handset, the guider, or the planetarium you already use. It sits beside them as a named mount desk for one job: which periodic error curve is live, which guiding sample still matches, and what the next person should read before tracking.

If two people share the observatory PC, each keeps a PEMPro style of their own. Extra mounts wait for their own title instead of crowding the live curve.

## Traffic Light

| Signal | On the PEMPro board | What you do |
|--------|----------------------|-------------|
| Green | Named curve, short live sample list | Continue the same PE run |
| Amber | Two mounts mixed in one curve | Split the set before you track |
| Red | No title, no note, PE unlabeled | Stop and name the curve first |
| Clear | Handoff written, live samples few | Close PEMPro and leave the desk |

## Open Order

1. Open the last PEMPro curve, not a new empty mount desk.
2. Read the sample list and the last handoff.
3. Finish one visible periodic error pass inside PEMPro.
4. Write what changed, then close with fewer unlabeled samples than you found.
5. If the set feels crowded, drop anything that belongs to a different PEMPro mount.

## After a Week

A week in PEMPro is not a thicker guess about the worm. It is the same title, a shorter live sample list, and a note that still makes sense before the next tracking run. Take finished curves off the live set so the next visit starts on the mount that still needs a sample.

Other programs stay where they are. PEMPro only keeps the path back: curve name, periodic error, guiding sample, handoff.

## Sign-off

- [ ] The PEMPro workspace name is short enough to scan
- [ ] Only the live mount is on the board
- [ ] A second person can read the handoff
- [ ] The last PEMPro curve still opens after a restart
- [ ] Finished samples are off the live PEMPro set

## Field Note

PEMPro is easier to trust when the mount desk stays smaller than the log pile it came from. Name the curve, keep the live sample, finish one visible PE pass, and write what changed.
